# Repository-local skills

This repository keeps its shared task skills in `.claude/skills`. Before
performing work covered by one of the entries below, read the referenced
`SKILL.md` in full and follow its instructions. The user’s instructions take
precedence over these skill instructions.

| Skill | Load when the request involves | Instructions |
| --- | --- | --- |
| `cl` | IBM i CL/CLLE/CLP code, batch jobs, job submission, menus, library lists, data areas, or job control | `.claude/skills/cl/SKILL.md` |
| `cpysrc` | Downloading an IBM i source member | `.claude/skills/cpysrc/SKILL.md` |
| `dds` | IBM i DDS source: PF, LF, DSPF, or PRTF creation, review, or validation | `.claude/skills/dds/SKILL.md` |
| `putsrc` | Uploading an IBM i source member | `.claude/skills/putsrc/SKILL.md` |
| `rpg` | RPG, RPGLE, or SQLRPGLE code creation, modification, or review | `.claude/skills/rpg/SKILL.md` |

If a request involves more than one listed area, load every applicable skill
before beginning work.
